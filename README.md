# Tenfold Quiz

A responsive ten-question general knowledge quiz that gets a fresh set of multiple-choice questions from the Open Trivia Database.

## Features

- Ten multiple-choice questions per round
- Randomized answer order
- Answer progress and score feedback
- Light and dark themes
- Option to load a fresh set of questions

## Tech Stack

- HTML
- CSS
- JavaScript
- Open Trivia Database API

## Run Locally

Open `index.html` in a modern web browser. An internet connection is required to load questions from the API.
